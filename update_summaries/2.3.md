derivative = np.diff(od_signal)

# 2. Global std of derivative (noise baseline)
std_diff = np.std(derivative)
mc_thresh = std_diff * stdev_thresh  # 20x multiplier

# 3. Sliding window max difference
for ii in range(1, window_samples + 1):
    diff_delayed = np.abs(od_signal[ii:] - od_signal[:-ii])
    max_diff = np.maximum(max_diff, padded_diff)

### 🎯 Why Optical Density, Not Raxw Intensity?

**Key Insight from MR_logic.md:**
- OD is logarithmically related to intensity: `OD = -log10(I/I₀)`
- Motion causes **multiplicative changes** in intensity but **additive changes** in OD
- OD units make thresholds more consistent across different baseline intensities
- The MATLAB code from the paper confirms: `currentOD = hmrR_Intensity2OD(currentfile.data)` happens **before** motion detection

This is a **critical implementation detail** that was documented in MR_logic.md after analyzing the original MATLAB code.
